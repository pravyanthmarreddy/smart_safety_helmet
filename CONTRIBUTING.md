# Contributing

1. Open an issue describing the bug or proposed improvement.
2. Include board model, module model, library versions, wiring changes, and reproducible steps.
3. Keep safety-related changes conservative and documented.
4. Do not claim sensor accuracy, radio range, or certification without evidence.
5. Test detection logic with simulated input before connecting hardware.
6. Never commit credentials, private worker data, or real location logs.
7. Submit a pull request with a concise summary and test notes.
